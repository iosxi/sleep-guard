# SleepGuard（スリープ防止）

指定した時間だけ Windows のスリープ（と、必要なら画面オフ）を止めておくための小さな常駐ツール。
仕組みは Win32 の `SetThreadExecutionState` で、電源プランの設定そのものは書き換えない。
プロセスが終われば元の挙動に戻るので、設定を戻し忘れる心配がない。

v6 から C（Win32 API 直）で書き直した。それまでは PowerShell スクリプトを ps2exe で
exe 化したものだった（v5 までのタグに残っている）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `SleepGuard.exe` | **これ 1 個で動く。** 依存は Windows 標準の DLL だけ（.NET も不要） |
| `sleepguard.c` | 本体のソース |
| `sleepguard.rc` / `resource.h` | ダイアログ・アイコン・バージョン情報のリソース |
| `sleepguard.manifest` | 見た目（コモンコントロール v6）と高 DPI 対応の宣言 |
| `sleepguard.ico` | アイコン（exe に埋め込まれる。16x16 のフレームもそのまま使う） |
| `build.cmd` | ビルド手順 |

## 使い方

`SleepGuard.exe` をダブルクリックする。

1. 「何時間スリープを防止しますか？」のダイアログが出る。
   - 15分 / 30分 / 45分 / 1時間 / 2時間 / 4時間 / 9時間（最長） から選ぶ（既定は 30分）
   - 「カスタム」を選ぶと分単位で指定できる（1〜540分。540 を超える値は 540 に丸められる）
   - 「ディスプレイも消さない」のチェックを外すと、スリープは止めるが画面は消える
2. 「開始」を押すとタスクトレイに常駐し、開始した旨の通知が出る。
3. 指定時間が経つと自動で解除して終了する。

## 途中でやめる

タスクトレイのアイコンから:

- **ダブルクリック** — 即座に解除して終了
- **右クリック** — 終了予定時刻の表示、「ディスプレイも消さない」の途中切り替え、
  「今すぐ解除して終了」

アイコンにマウスを乗せると残り時間が出る（15 秒ごとに更新、最後の 1 分は毎秒）。

## コマンドライン

引数を付けるとダイアログを出さずにすぐ開始する。ショートカットやタスクスケジューラ、
動作確認の自動化向け（秒指定の `-s` は主に動作確認用。ダイアログには短い選択肢を置かない）。

```
SleepGuard.exe -m 90            90 分
SleepGuard.exe -s 30            30 秒
SleepGuard.exe -m 60 -nodisplay 60 分、画面は消えてよい
```

`-` の代わりに `/` でもよい。上限は 9 時間で、それを超える値は丸められる。

## 解除後のスリープについて（実測）

解除すると実行状態の要求は即座に消え、プロセスも残らない（旧 PowerShell 版・C 版とも実測で確認）。
ただし解除した瞬間に寝るとは限らない。実測（画面オフ 1 分・スリープ 2 分に設定、
ガード中はずっと無操作）では:

| 解除時の状態 | 解除からスリープまで |
| --- | --- |
| 「ディスプレイも消さない」ON（画面が点いたまま解除） | 約 61 秒 ＝ 画面オフの設定時間 |
| 「ディスプレイも消さない」OFF（画面はもう消えている） | 約 1 秒 |

つまり、ガード中も無操作の時間は積み上がっていて、解除後は**画面が消えた時点で**寝る。
画面オフ 3 分の設定なら、画面を点けたまま解除した場合は解除の約 3 分後にスリープする。

## 仕様メモ

- 15 秒ごとに実行状態を再アサートしているので、他のアプリに横から解除されても復帰する。
- 終了判定は 1 秒刻み。トレイからの解除は即時に効く。
- 上限は 9 時間（540分）。
- エクスプローラが再起動してもトレイアイコンを出し直す。

## ビルド

MinGW-w64 の `gcc` と `windres` が PATH にあれば、`build.cmd` を実行するだけ。

```
build.cmd
```

（WinLibs の gcc 16 で確認。MinGW が自動で足す既定の manifest と自前の manifest が
衝突するので、`build\` に空の `default-manifest.o` を作って差し替えている。
詳しくは `build.cmd` のコメント。）

exe のメタデータ（`sleepguard.rc` の VERSIONINFO）:

| 項目 | 値 |
| --- | --- |
| ProductName | `SleepGuard` |
| FileDescription | `スリープ防止` |
| CompanyName | `nekoryu` |
| Comments | `指定時間だけWindowsのスリープを防止します` |
| FileVersion | `2.1.0` |

exe を更新したらリリースにも差し替えて添付すること。
