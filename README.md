# SleepGuard（スリープ防止）

指定した時間だけ Windows のスリープ（と、必要なら画面オフ）を止めておくための小さな常駐ツール。
仕組みは Win32 の `SetThreadExecutionState` で、電源プランの設定そのものは書き換えない。
プロセスが終われば元の挙動に戻るので、設定を戻し忘れる心配がない。

## ファイル構成

| ファイル | exe を使うなら | 役割 |
| --- | --- | --- |
| `SleepGuard.exe` | **必須** | 単体で動く実行ファイル。ふだんはこれをダブルクリックする |
| `SleepGuard.ps1` | 不要 | 本体のスクリプト。exe はこれを埋め込んでいる。ビルド元 |
| `sleepguard.ico` | 任意 | アイコン。exe にも埋め込み済みだが、隣に置くとトレイ表示が少しきれいになる |

**exe だけあれば動く。** 他のフォルダに `SleepGuard.exe` 1 個だけコピーしても起動する
（実測済み）。配布や持ち運びのときは exe 1 個で足りる。

`sleepguard.ico` だけは少し事情がある。スクリプトはまず exe の隣の ico を探し、
無ければ exe に埋め込まれたアイコンを使う。絵柄はどちらも同じだが、ico ファイルには
16x16 専用のフレームが入っている一方、埋め込みから取れるのは 32x32 だけなので、
タスクトレイの小さいアイコンは ico を隣に置いたほうがわずかに鮮明になる。
気にならなければ exe 単体で問題ない。

## 使い方

`SleepGuard.exe` をダブルクリックする。

1. 「何時間スリープを防止しますか？」のダイアログが出る。
   - 30分 / 1時間 / 2時間 / 4時間 / 9時間（最長） から選ぶ（既定は 1時間）
   - 「カスタム」を選ぶと分単位で指定できる（1〜540分。540 を超える値は 540 に丸められる）
   - 「ディスプレイも消さない」のチェックを外すと、スリープは止めるが画面は消える
2. 「開始」を押すとタスクトレイに常駐し、開始した旨のバルーンが出る。
3. 指定時間が経つと自動で解除して終了する。

## 途中でやめる

タスクトレイのアイコンから:

- **ダブルクリック** — 即座に解除して終了
- **右クリック** — 終了予定時刻の表示、「ディスプレイも消さない」の途中切り替え、
  「今すぐ解除して終了」

アイコンにマウスを乗せると残り時間が出る（15秒ごとに更新）。

## 仕様メモ

- 15秒ごとに実行状態を再アサートしているので、他のアプリに横から解除されても復帰する。
- 上限は 9時間（540分）。
- コマンドラインオプションは無い。起動すると必ずダイアログが出る。

## ビルド

`SleepGuard.ps1` を [ps2exe](https://github.com/MScholtes/PS2EXE) で exe 化したもの
（exe のエントリポイントが `Main(String[])` で、下のメタデータが .NET アセンブリ属性として
入っていることから。`PS2EXE` の署名文字列自体は埋まっていないので断定はできない）。

現在の `SleepGuard.exe` が持つメタデータ:

| 項目 | 値 |
| --- | --- |
| ProductName | `SleepGuard` |
| FileDescription / Title | `スリープ防止` |
| CompanyName | `nekoryu` |
| Description | `指定時間だけWindowsのスリープを防止します` |
| FileVersion | `1.1.0` |

これを保ったまま作り直すなら:

```powershell
Invoke-PS2EXE .\SleepGuard.ps1 .\SleepGuard.exe `
  -iconFile .\sleepguard.ico -noConsole -STA `
  -product 'SleepGuard' -title 'スリープ防止' -company 'nekoryu' `
  -description '指定時間だけWindowsのスリープを防止します' -version '1.1.0'
```

exe を更新したらリリースにも差し替えて添付すること。
